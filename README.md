# Application de gestion d'une bibliothèque de quartier

C;est une Application web permettant de gérer les auteurs, les adhérents, les livres et les emprunts d'une bibliothèque.

## Technologies

- Node.js
- Express.js
- PostgreSQL
- HTML
- CSS
- JavaScript

## Fonctionnalités

- Gestion des auteurs : ajout, modification, suppression
- Gestion des adhérents : ajout, modification, suppression 
- Historique des emprunts par adhérent
- Gestion des livres : ajout, modification, suppression
- Recherche de livres par titre ou auteur
- Pagination des livres
- Création et retour des emprunts
- Gestion automatique de la disponibilité des livres
- Détection des emprunts en retard
- Tableau de bord avec statistiques
